# Compose with real language and text shape

ID: cmp-text-shape. Source: [S14](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/text-wrap-style).

Teach composition with real headline lengths, qualifications, and action labels. Adjust measure, wrapping, layout, and scale together. Approved meaning constrains copy changes. Avoid brittle manual breaks; deliberate editorial breaks are acceptable when tested.

Application A: a concise statement uses a narrow measure beside an image. Application B: a longer precise offer spans above supporting facts without becoming an unsupported slogan.

Counterexample: shrink all text or remove an important qualification to preserve a reference silhouette.

Mobile: normal wrapping must remain legible when enhancements are unavailable. Test long names, translated text, and zoom.

Storyboard: record information hierarchy rather than exact line counts. Review: locate clipping, awkward fragments, excessive measures, or changed meaning. Use the existing editorial revision path for copy changes.
