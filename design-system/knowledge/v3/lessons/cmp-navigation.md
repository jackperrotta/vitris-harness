# Make navigation express the visitor's choices

ID: cmp-navigation. Sources: [S20](https://www.w3.org/WAI/ARIA/apg/practices/read-me-first/), [S06](https://design.google/library/expressive-material-design-google-research).

Teach orientation through labels, location, grouping, and useful actions. Geometry follows route complexity and direction. Avoid fixed item counts and industry-specific header templates.

Application A: a small practice exposes essential routes and an inquiry path. Application B: a broad catalog uses route groups and contextual interior navigation.

Counterexample: an unlabeled experimental menu conceals the service architecture, or an oversized menu overwhelms a simple site.

Mobile: preserve labels, keyboard access, dismissal, and the primary task. A drawer is optional.

Storyboard: record shared chrome at page/site scope, without adding artificial navigation sections. Review: execute route-finding tasks and inspect focus, overlay obstruction, and sticky behavior.

## Authority and use

This is an original design-teaching hypothesis. It is advisory and does not change factual, accessibility, or functional requirements. Adapt it to verified business evidence and inspect the current render before accepting an outcome. The applications above are contrasting examples, not copyable site presets.
