# Give sparse-media sites useful visual artifacts

ID: cmp-sparse-media. Sources: [S01](https://every-layout.dev/rudiments/composition/), [S02](https://www.nngroup.com/articles/principles-visual-design/).

Teach expressive organization of real content through checklists, scope ledgers, document structures, decision maps, timelines, and carefully set language. Use when photography cannot carry the page. These possibilities do not define a sparse-site template.

Application A: a consultation page organizes preparation and meeting scope. Application B: a technical service distinguishes included and excluded work in a readable ledger.

Counterexample: fabricated dashboards, results, logos, or portraits supply false credibility. Illustrative samples must not masquerade as actual deliverables.

Mobile: simplify dense artifacts while preserving hierarchy and qualifications.

Storyboard: state which uncertainty the artifact resolves and which facts support it. Review: assess clarity and specificity without penalizing absent photography or rewarding generic diagrams.

## Authority and use

This is an original design-teaching hypothesis. It is advisory and does not change factual, accessibility, or functional requirements. Adapt it to verified business evidence and inspect the current render before accepting an outcome. The applications above are contrasting examples, not copyable site presets.
