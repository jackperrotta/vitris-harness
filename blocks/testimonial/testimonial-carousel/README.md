# testimonial-carousel

Buttoned testimonial carousel.

- **Category:** testimonial
- **Media:** portraits
- **Registers:** trade, beauty, food
- **Variants:** (none)

## Slots

| Slot | Content |
|------|---------|
| `eyebrow` | Optional `<p class="eyebrow">` |
| `heading` | `<h2>` |
| `lede` | Optional `<p class="lede">` |
| `cards` | 4–8 testimonial `<figure class="card">` slides (same markup as testimonial-grid) |
