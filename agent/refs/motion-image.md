# Image followed by a quiet caption

Let authentic evidence earn attention: subtle 1.015 to 1 scale, then a caption. Preserve crop, dimensions, alt text, provenance and links. Keep primary hero/LCP media still. This is a short sequence, followed by quiet reading.

```html
<figure id="detail" data-motion="sequence" data-motion-duration="650" data-motion-stagger="90" data-motion-distance="6" data-motion-mobile="static">
 <img data-motion-child data-motion-role="image" src="/media/verified-detail.jpg" width="1000" height="600" alt="Accurately described supplied detail">
 <figcaption data-motion-child data-motion-role="caption">Unchanged supplied caption.</figcaption>
</figure>
```

Allow crop margin; avoid scale for edge-critical evidence. Mobile static is often clearer. No captions covering evidence, invented provenance, image swapping or animation on every gallery tile. Normal/static/reduced hold content/layout/media fixed. Watch actual crop and caption timing and keyboard focus; see image lesson.
