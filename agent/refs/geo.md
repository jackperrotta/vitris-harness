# AI search visibility

For Google's AI features, [official guidance](https://developers.google.com/search/docs/appearance/ai-features) says existing SEO foundations apply and that no special AI file or schema is required. That does not set policy for every other provider. The live page was not re-checked on 2026-09-22.

Answer the visitor's actual questions in visible text. Identify the business, services, and locations only where the facts support them. Do not add FAQ blocks everywhere, invent credentials, publish duplicate city pages, or promise citations.

`llms.txt` and similar files are optional experiments. They are not a launch requirement. Search-discovery preferences and AI-training preferences are separate. Do not change Cloudflare bot settings from this guidance.
