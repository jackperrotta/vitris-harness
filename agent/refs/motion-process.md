Stroke draw has measured paint cost: few simple paths only, SVG aria-hidden, no essential text in the SVG. Complete strokes remain without JS/reduced/off/failure. For scroll progress use existing progress with a separate stable trigger and reachable normalized range. Mobile can use static.
